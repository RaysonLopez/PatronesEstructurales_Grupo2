# Documentación UML — Patrón Decorator

Esta carpeta contiene los diagramas UML correspondientes a la implementación del patrón de diseño estructural Decorator en un sistema de configuración de computadoras desarrollado en Java.

Se incluyen diagramas de clases, casos de uso, actividades, secuencia y objetos, con el propósito de documentar la arquitectura, las relaciones entre componentes y el comportamiento del sistema.

Cada subcarpeta contiene las representaciones gráficas y sus respectivos códigos fuente editables, como parte de la documentación técnica del proyecto.
