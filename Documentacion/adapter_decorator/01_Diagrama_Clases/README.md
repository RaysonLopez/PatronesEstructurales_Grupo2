Diagramas de clases: Adapter y Decorator
Descripción
Este proyecto presenta dos ejemplos de diagramas de clases UML para comprender cómo se aplican los patrones de diseño estructurales Adapter y Decorator en un sistema de notificaciones.
- Adapter (Adaptador): permite que el sistema use un servicio externo de SMS aunque su interfaz sea diferente de la interfaz esperada.
- Decorator (Decorador): permite agregar funciones opcionales, como el registro de actividad y el cifrado, sin modificar la clase principal que envía notificaciones.
